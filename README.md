# Palavras que Acolhem — site de vendas

Site estático publicado em https://palavras-que-acolhem-site.pages.dev/ pelo Cloudflare Pages.

## Publicação

O Cloudflare Pages acompanha a branch `main` deste repositório. Cada novo commit enviado ao GitHub nessa branch inicia uma implantação automática.

O site é composto por `index.html` e `assets/`. Antes de enviar mudanças, confira os três links de checkout, as imagens e o conteúdo da página. Arquivos locais e privados estão excluídos pelo `.gitignore`.
