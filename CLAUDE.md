# Palavras que Acolhem — publicação

Este diretório é a origem do site público. Edite `index.html` e os arquivos de `assets/` para mudar a página. Preserve os três links de checkout e confira a versão local antes de encerrar cada tarefa.

Ao terminar um turno, o hook do projeto verifica mudanças nesses arquivos, cria um commit na branch `main` e envia para o GitHub. O Cloudflare Pages publica automaticamente cada push. Se o hook informar falha, avise o usuário; não diga que a mudança está pública antes de confirmar o deploy.

O repositório é público. Não salve credenciais, dados pessoais de clientes, arquivos de configuração secretos ou material privado neste diretório.
